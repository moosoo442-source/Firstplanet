# 📖 CharaWiki v3.1

나무위키 스타일 캐릭터 위키 빌더 — GitHub Pages 즉시 배포 가능

---

## 🚀 GitHub Pages 배포

```bash
git init
git add .
git commit -m "CharaWiki v3.1"
git remote add origin https://github.com/유저명/레포명.git
git push -u origin main
```
GitHub → Settings → Pages → Source: **main / root** → Save

## ✨ 전체 기능

### 💾 자동 저장
- 타이핑 즉시 localStorage 자동 저장
- 브라우저 닫아도 데이터 유지
- `Ctrl+S` 즉시 저장
- JSON 백업 내보내기/불러오기

### 👥 멀티 캐릭터
- 캐릭터 여러 명 생성·관리·삭제
- 사이드바에서 빠른 전환
- 캐릭터별 독립 스타일

### 📄 하위 페이지
- 페이지 무제한 추가 (2기, 외전, 관계도 등)
- 탭으로 전환

### 🎨 테마 & 꾸미기
| 설정 | 옵션 |
|---|---|
| 테마 | 라이트·다크·세피아·핑크·민트·네이비·갤럭시·레트로 |
| 강조 색상 | 프리셋 7종 + 직접 선택 |
| 폰트 | 모던·명조·모노 |
| 인포박스 | 클래식·카드·미니멀 |
| 레이아웃 | 우측·좌측·상단 |
| 배경 패턴 | 없음·격자·도트·줄무늬 |
| 구분선 | 실선·점선·그라데이션·없음 |
| 글자 크기 | 13~20px |

### ✏️ 편집 기능 (편집 버튼 클릭 후)
- 모든 텍스트 인라인 클릭 편집
- 커버 이미지·아바타 업로드
- 인포박스: 항목·소제목 추가/삭제, 이미지·필터
- 섹션 11종: 텍스트·목록·능력치·인물관계·타임라인·어록·갤러리·유튜브·외부링크·스포일러·표
- 섹션 드래그 순서 변경 / ↑↓ 버튼 이동
- 갤러리 이미지 라이트박스 확대
- 유튜브 실제 재생 (iframe embed)
- 분류 태그 추가/삭제

### 🔗 공유
- URL 인코딩 읽기 전용 공유 (서버 불필요)
- JSON 전체 백업/복원

### 📱 완전 반응형
- 모바일 (480px 이하)
- 태블릿 (768px 이하)
- 소형 데스크탑 (1100px 이하)
- 대형 데스크탑
- 다크모드 OS 설정 대응
- `prefers-reduced-motion` 접근성 대응
