# 📖 CharaWiki — 캐릭터 위키 페이지 템플릿

나무위키 / 위키백과 스타일의 캐릭터 소개 페이지 템플릿입니다.  
**GitHub Pages**에 그대로 올려서 바로 사용할 수 있어요!

---

## ✨ 기능

### 🎨 테마 (6가지)
| 테마 | 설명 |
|---|---|
| ☀️ 기본 (화이트) | 위키백과 스타일 깔끔한 흰색 |
| 🌙 다크 | 어두운 나무위키 스타일 |
| 🌸 사쿠라 | 연분홍 파스텔 소녀 감성 |
| 🌊 오션 | 딥 블루 시원한 느낌 |
| 🌿 포레스트 | 초록 자연 감성 |
| ⭐ 갤럭시 | 보라+별빛 우주 테마 |

### ✨ 꾸미기 기능
- **폰트 변경**: 고딕체 / 명조체 / 손글씨체
- **배경 패턴**: 없음 / 격자 / 도트 / 대각선
- **인포박스 테두리**: 실선 / 점선 / 이중선 / 그림자
- **구분선 스타일**: 실선 / 점선 / 그라데이션 / 이중선
- **강조 색상**: 6가지 프리셋 + 직접 선택
- **글자 크기**: 13px ~ 20px 슬라이더

### 📝 편집 기능
- 제목, 부제목, 본문 텍스트 **클릭하여 직접 편집**
- 인포박스 항목 **추가** 가능
- 캐릭터 **이미지 업로드**
- 인물관계 카드 **추가**
- 어록 **추가**
- 행적(타임라인) **추가**
- 설정은 **자동 저장** (localStorage)

## 🚀 GitHub Pages 배포 방법

### 방법 1 — main 브랜치 루트 배포
```bash
# 이 폴더를 그대로 레포지토리 루트에 넣기
git init
git add .
git commit -m "Initial CharaWiki"
git remote add origin https://github.com/유저명/레포명.git
git push -u origin main
```
그 다음 GitHub 레포 → **Settings → Pages → Source: main / root** 선택 → Save

### 방법 2 — docs 폴더
파일들을 `/docs` 폴더 안에 넣고 Pages 설정에서 `Branch: main / docs` 선택

## 📁 파일 구조

```
charawiki/
├── index.html   ← 메인 페이지 (이것만 있어도 됨)
├── style.css    ← 전체 스타일 + 테마
├── script.js    ← 인터랙션 로직
└── README.md
```

## 💡 커스터마이징 팁

- `index.html` 안의 텍스트를 직접 수정하면 캐릭터 기본 정보를 바꿀 수 있어요
- CSS의 `:root` 변수를 수정하면 기본 테마 색상을 바꿀 수 있어요
- 섹션을 복사/삭제해서 원하는 항목만 남길 수 있어요
