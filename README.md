# 📖 CharaWiki v2.0 — 캐릭터 위키 페이지 템플릿

나무위키 / 위키백과 스타일의 캐릭터 소개 페이지 템플릿입니다.  
**GitHub Pages**에 그대로 올려서 바로 사용할 수 있어요!

---

## ✨ v2.0 신규 기능 전체 목록

### 🔐 관리자 / 방문자 모드
| 구분 | 설명 |
|---|---|
| 방문자 | 읽기 전용. 꾸미기(테마·폰트 등)는 자유롭게 사용 가능 |
| 관리자 | 🔒 버튼 클릭 → 비밀번호 입력 → 편집 모드 활성화 |
| 최초 설정 | 처음 실행 시 원하는 비밀번호로 직접 설정 |
| 비밀번호 변경 | 꾸미기 패널 하단 → 비밀번호 변경 |
| 보안 방식 | SHA-256 해시로 localStorage에 저장 (서버 불필요) |

### 🎨 테마 (9가지)
| 테마 | 설명 |
|---|---|
| ☀️ 기본 (화이트) | 위키백과 스타일 깔끔한 흰색 |
| 🌙 다크 | 어두운 나무위키 스타일 |
| 🌸 사쿠라 | 연분홍 파스텔 소녀 감성 |
| 🌊 오션 | 딥 블루 시원한 느낌 |
| 🌿 포레스트 | 초록 자연 감성 |
| ⭐ 갤럭시 | 보라+별빛 우주 테마 |
| 📼 레트로 | 빈티지 황갈색 복고풍 |
| 🎃 할로윈 | 주황+검정 호박 테마 |
| 🎄 크리스마스 | 초록+빨강 겨울 테마 |

### ✨ 꾸미기 기능 (대폭 확장)
- **폰트**: 고딕 / 명조 / 손글씨(Gaegu) / 둥근체(Gowun)
- **배경 패턴**: 없음 / 격자 / 도트 / 대각선 / 십자
- **배경 이미지**: 직접 업로드 + 불투명도 조절
- **인포박스 테두리**: 실선 / 점선 / 이중선 / 그림자
- **구분선 스타일**: 실선 / 점선 / 그라데이션 / 이중선
- **카드 스타일**: 플랫 / 입체(raised) / 글래스모피즘
- **애니메이션**: 없음 / 보통 / 화려하게
- **커스텀 커서**: 기본 / ⭐별 / ❤️하트 / 🐱고양이
- **강조 색상**: 7가지 프리셋 + 직접 선택
- **글자 색상**: 직접 선택 + 초기화
- **글자 크기**: 13px ~ 20px 슬라이더
- **인포박스 위치**: 우측 / 좌측 / 상단

### 📝 편집 기능 (관리자 전용)
- 제목·부제목·본문 클릭 편집
- 인포박스 항목 추가 / 섹션 헤더 추가
- **섹션 추가 / 삭제 / 위아래 이동**
- **태그 추가 / 클릭 삭제**
- **능력치 바 추가 / 수치 조절 / 삭제**
- 인물관계 카드 추가 / 이모지 순환 변경 / 삭제
- 어록 추가 / 삭제
- 행적(타임라인) 추가 / 삭제

### 🖼️ 미디어
- 캐릭터 이미지 업로드 (관리자)
- 이미지 필터: 없음 / 세피아 / 흑백 / 밝게 / 쿨톤
- 이미지 캡션 편집
- **갤러리 섹션**: 다중 이미지 업로드 + 라이트박스(키보드 ←→ 지원)
- **YouTube 영상 임베드**: URL 붙여넣기로 간편 추가

### 🔗 링크 & 공유
- **외부 링크 섹션**: 아이콘 이모지 + 이름 + URL 자유 추가
- **URL 복사** 버튼
- **인쇄 / PDF 저장** 버튼 (출력용 스타일 자동 적용)
- **JSON 내보내기 / 불러오기** (데이터 백업 & 복원)

### 💾 저장
- 꾸미기 설정 localStorage 자동저장
- JSON 파일로 전체 내용 백업 가능

## 🚀 GitHub Pages 배포 방법

### 방법 1 — main 브랜치 루트 배포
```bash
git init
git add .
git commit -m "CharaWiki v2.0"
git remote add origin https://github.com/유저명/레포명.git
git push -u origin main
```
GitHub 레포 → **Settings → Pages → Source: main / root** → Save

### 방법 2 — docs 폴더
파일들을 `/docs` 폴더 안에 넣고 Pages 설정에서 `Branch: main / docs` 선택

## 💡 커스터마이징 팁

- `index.html` 안의 텍스트를 직접 수정하면 캐릭터 기본 정보를 바꿀 수 있어요

- 섹션을 복사/삭제해서 원하는 항목만 남길 수 있어요
