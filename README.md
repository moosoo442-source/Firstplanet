## 🚀 GitHub Pages 배포

```bash
git init
git add .
git commit -m "CharaWiki v3"
git remote add origin https://github.com/유저명/레포명.git
git push -u origin main
```
GitHub → Settings → Pages → Source: **main / root** → Save

## ✨ 주요 기능

### 📦 자동 저장
- 편집 즉시 localStorage에 자동 저장
- 브라우저를 닫아도 데이터 유지
- `Ctrl+S` 단축키로 즉시 저장

### 👥 멀티 캐릭터
- 캐릭터 여러 명 생성·관리
- 사이드바에서 빠른 전환
- 캐릭터별 독립적인 스타일/설정

### 📄 하위 페이지
- 캐릭터당 페이지 무제한 추가
- 탭으로 전환 (예: 메인 / 2기 설정 / 외전)

### 🎨 테마 & 꾸미기 (캐릭터별 독립)
- 테마 8종: 라이트·다크·세피아·핑크·민트·네이비·갤럭시·레트로
- 강조 색상 직접 선택
- 폰트 3종, 배경 패턴 4종
- 인포박스 스타일·레이아웃 변경

### ✏️ 편집 기능 (편집 모드)
- 모든 텍스트 인라인 편집
- 커버 이미지·아바타 업로드
- 인포박스 항목 추가/삭제
- 섹션 11종 추가: 텍스트·목록·능력치·인물관계·타임라인·어록·갤러리·유튜브·외부링크·스포일러·표
- 섹션 드래그 순서 변경
- 분류 태그 추가/삭제

### 🔗 공유
- URL 인코딩으로 읽기 전용 공유 (서버 불필요)
- 전체 백업 JSON 내보내기/불러오기

### 📱 완전 반응형
- 모바일·태블릿·데스크탑 모두 대응
- 사이드바 자동 접힘/펼침

---

## ⌨️ 단축키

| 단축키 | 기능 |
|---|---|
| `Ctrl+S` | 저장 (편집 완료) |
| `Ctrl+E` | 편집 모드 전환 |
| `Esc` | 모달/라이트박스 닫기 |
