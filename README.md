# 📖 CharaWiki v2 — 캐릭터 위키 페이지 템플릿

나무위키 / 위키백과 스타일 캐릭터 소개 페이지. GitHub Pages로 바로 배포 가능!

## ✨ v2 기능 목록

### 🎨 테마 (9가지)
☀️ 기본 · 🌙 다크 · 🌸 사쿠라 · 🌊 오션 · 🌿 포레스트 · ⭐ 갤럭시 · 📺 레트로 · 🎃 할로윈 · 🎄 크리스마스

### ✨ 꾸미기
- 폰트 4종 (고딕/명조/손글씨/큐트)
- 배경 패턴 6종 (격자/도트/대각선/물결/별/없음)
- 배경 이미지 업로드 + 불투명도 조절
- 인포박스 테두리 5종 (실선/점선/이중선/그림자/글로우)
- 섹션 구분선 5종
- 섹션 카드 스타일 ON/OFF
- 커스텀 커서 + 이모지 트레일 (별/하트/펜)
- 애니메이션 강도 조절
- 인포박스 위치 (우측/좌측/상단)
- 강조 색상 8종 프리셋 + 직접 선택
- 글자 크기 슬라이더
- 모든 설정 자동 저장

### ✏️ 편집
- 모든 텍스트 클릭 편집
- 섹션 추가 / 삭제
- 갤러리 섹션 (여러 장 이미지 + 캡션)
- 유튜브 영상 임베드 섹션
- 외부 링크 섹션
- 인포박스 항목/소제목 추가
- 캐릭터 이미지 업로드 + 필터 (원본/세피아/흑백/밝게)
- 이미지 캡션
- 인물관계 카드 추가/삭제 + 이모지 선택
- 타임라인 추가/삭제
- 어록 추가/삭제
- 능력치 항목 추가
- 분류 태그 추가/삭제
- JSON 내보내기/불러오기
- URL 복사
- 인쇄 / PDF 저장
- 목차 접기/펼치기

## 🚀 GitHub Pages 배포

```bash
git init
git add .
git commit -m "CharaWiki v2"
git remote add origin https://github.com/유저명/레포명.git
git push -u origin main
```
GitHub → Settings → Pages → Source: **main / root** → Save
